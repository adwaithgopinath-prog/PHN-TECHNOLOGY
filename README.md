**PHN Technology** is a premier technical education and industrial innovation platform dedicated to bridging the gap between academia and industry. This production-ready web application showcases our strategic collaborations with India's elite institutions (IITs, NITs, IIITs) and our commitment to fostering a future-ready tech ecosystem.

---

## ✨ Key Features

### 🏢 Institutional Excellence
*   **CoE Lab Showcases**: Explore our Centers of Excellence launched at **IIT Patna, IIT Jammu, NIT Delhi**, and more.
*   **Strategic Partnerships**: A dynamic, filtered grid featuring collaborations with premier academic bodies and industry leaders like **BELOP and TCIL**.

### 📰 Dynamic Newsroom
*   **Interactive News Showcase**: High-aesthetic slider featuring the latest awards, lab inaugurations, and technological breakthroughs.
*   **Visual Storytelling**: Integrated video and high-resolution media galleries for an immersive experience.

### 📅 Event Management
*   **Upcoming Launches**: A sophisticated timeline of upcoming tech lab launches across India.
*   **Real-time Notifications**: "Notify Me" functionality for upcoming industrial visits and launches.

### 💎 Premium User Experience
*   **Glassmorphism & Micro-animations**: Built with Framer Motion for smooth, high-end transitions.
*   **Responsive Architecture**: Fully optimized for Desktop, Tablet, and Mobile devices.
*   **Smart Modals**: Detailed popups for job training, event specifics, and news articles.

## 🚀 Getting Started

### Prerequisites
*   [Node.js](https://nodejs.org/) (v18.0.0 or higher)
*   [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/adwaithgopinath-prog/PHN-TECHNOLOGY.git
    cd PHN-TECHNOLOGY
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Launch the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```
